The five tool types

From agentcore add tool --type. The last column is the distinction that matters.

typewhat it iswho executes it
agentcore_code_interpreterbuilt-in sandboxed code executionmanaged loop
agentcore_browserbuilt-in headless browser the agent drivesmanaged loop
agentcore_gatewayyour APIs / Lambdas exposed as MCP toolsmanaged loop
remote_mcpany MCP server, by URLmanaged loop
inline_functionyou declare name + JSON input schema onlythe caller
