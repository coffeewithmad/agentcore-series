What runs on a request

The Runtime calls your entrypoint; inside it, the real LangGraph graph executes — branch and all.

The whole integration, in full

Everything that makes the existing agent deployable. Nothing else changes.

# main.py — the only AgentCore-specific file
from bedrock_agentcore import BedrockAgentCoreApp
from trip_graph import trip_graph      # your existing agent, untouched

app = BedrockAgentCoreApp()

@app.entrypoint
def plan_trip(payload, context):
    result = trip_graph.invoke({"request": payload.get("prompt")})
    return result["messages"][-1].content

app.run()
